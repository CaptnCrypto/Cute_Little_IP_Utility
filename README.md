# Cute_Little_IP_Utility
*Cute Little Geolocation Utility (CLGU)** is a desktop tool for Windows, Linux, and macOS that extracts IPv4 and IPv6 addresses from multiple documents, including Word, LibreOffice, text files, spreadsheets, and searchable PDFs. Its GUI lets you geolocate public IPs, optionally check their existing VirusTotal reputation reports using your API key, and export combined results to CSV. CLGU removes duplicates, tracks source filenames and occurrence counts, and includes location, ISP, organization, and ASN information when available. Documents stay on your computer; only queried IPs are sent to the selected services. Standalone builds include Python and required dependencies.
